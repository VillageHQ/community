# Security

Please report security problems privately. Don't open a public issue.

Email [security@village.ai](mailto:security@village.ai), with **[URGENT]** in the subject if members' data or accounts are at risk. Tell us what you found, how to reproduce it and which version you ran. **Admin**, **Settings** shows the version.

Don't include real members' data, keys or tokens.

## What we fix

We fix the latest `main`. Each community runs its own copy, so we can't patch yours for you: the README explains [how to update](README.md#getting-updates).
