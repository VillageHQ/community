## Broke it / defects found

1. **Waiting list at 390 px hides the "Not them" flag** (`v1-waiting-390.png`). In each row the `.fh-who` column collapses to width 0. Name, email and the new "Not them" note are invisible, and only the avatar and buttons show. Nora's row (unflagged) is the same, so the layout bug was already there. But it means the fix's flag can't be seen on a phone.
2. **The "Not them" and "Expired" pills stretch across the whole column** instead of sizing to their text (`v1-waiting-1280.png`, `v4-invites-expired-*.png`). The explanation next to them is cut off with an ellipsis: "…We signed this p…" on the waiting list, and "ended 9…" / "sent 1…" on Invites. So the "ended <date>" text is not readable at 1280 or 390 without hovering.
3. **"Yes, this is them" is still offered** for a member flagged "Not them". One click would confirm the impostor again. Consider hiding it or asking "Are you sure?".
4. **A second "It wasn't me" press returns 200 and writes a duplicate audit row.** It does no harm, but the audit log shows the same event twice.
5. **The not-me link never expires.** It is an HMAC of the member id only. A real member who joined normally can press it from their own mailbox months later and be signed out, lose their password and become unconfirmed. Only that mailbox has the link, so the risk is low, but this may not be intended.
6. **Copy on a fresh install with no community name:** the subject reads "Your Your community invite was used" (default name "Your community").
7. `/api/network/paths` for Tom still returns `summary: "Amara knows Tom."` and a `paths[]` entry with Amara as introducer after she paused (`connectors: []`). No screen I found shows it (`intro-other-paths.tsx` reads `connectors` only), but the API still says that a paused member knows the person.
8. Not this build: search cards show the placeholder "Title, Company · City". The console has 2 errors, both 404 on `/demo/logos/company.svg` (fake Village has no headline/logo). No other console errors were seen on the not-me page.
